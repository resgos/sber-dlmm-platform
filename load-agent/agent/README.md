# Как подключить агента к любому LLM-харнессу

Файл `SYSTEM_PROMPT_BODY.md` — переносимый системный промпт агента нагрузочного
тестирования. Он рассчитан на **слабые модели**: вся аналитика (перцентили, вердикт,
диагностика) выполняется инструментом `../bin/loadgen.mjs`, модель только выполняет
конвейер команд и пересказывает вывод.

## Требования к харнессу

Агенту нужны всего три инструмента:

| Инструмент | Зачем |
|---|---|
| shell / exec | запускать `node loadgen.mjs ...` |
| чтение файла | читать сценарии и JSON-результаты |
| запись/правка файла | создавать и править сценарий *.json |

Модель: подойдёт любая (Qwen Coder, GigaChat, Haiku, локальная 7-14B). Промпт не требует
рассуждений — только следования нумерованным шагам.

**Важно про установку:** сам `loadgen.mjs` — zero-dependency, `npm install` ему НЕ нужен.
Достаточно Node.js >= 18 в PATH. Внутренние SberOSC-реестр / `.npmrc` / сертификаты нужны
только чтобы поставить сам харнесс (`qwen` и т.п.), но не для запуска инструмента.

## Подключение

1. Скопируйте папку `load-agent/` в репозиторий или на стенд (нужен только Node.js >= 18,
   зависимостей нет).
2. Возьмите содержимое `SYSTEM_PROMPT_BODY.md` **после** YAML-frontmatter (строки между
   `---` в начале файла отбросьте — это метаданные) и поставьте его системным промптом агента.
3. **Claude Code** — ничего делать не нужно: агент уже зарегистрирован как
   `.claude/agents/load-tester.md`, скилл-обёртка — `/load-test`.
4. **Qwen Code (Qwen Coder)** — тоже ничего: агент уже лежит как `.qwen/agents/load-tester.md`
   (Qwen Code сам подхватывает субагентов из `.qwen/agents/` проекта или `~/.qwen/agents/`).
   Вызов — автоделегированием, явно по имени «load-tester» или через `/agents`. Коннект к
   модели — это ваш вход в Qwen Coder (`chat.qwen.ai`), в файле агента только `model: inherit`.
5. **Другой LLM (GigaChat и т.п.)** — поставьте тело `SYSTEM_PROMPT_BODY.md` системным промптом
   в своём оркестраторе; endpoint+токен модели — в его конфиге/окружении, не в инструменте.

> Тело промпта в трёх файлах (`.claude/agents/`, `.qwen/agents/`, `SYSTEM_PROMPT_BODY.md`)
> одинаковое — канонический источник `SYSTEM_PROMPT_BODY.md`, при правке синхронизируйте все три.

## Проверка, что агент работает

Дайте агенту задание: «Прогони нагрузочный тест на http://localhost:8080, эндпоинты
api/v1/pools и api/v1/tokens, логин ivanov@example.com / Demo1234».
Правильное поведение: probe → сценарий → validate → run --smoke → run → отчёт
с дословным блоком «==== ИТОГ ====».
