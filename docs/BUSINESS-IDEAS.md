# Бизнес-идеи — Sber DLMM

Бэклог продуктовых/монетизационных гипотез для платформы концентрированной
ликвидности (рынок РФ, эталон UX — Meteora). Каждая идея: **ценность →
монетизация → усилие (S/M/L)** + что переиспользуем из уже построенного движка.
Не план — гипотезы для приоритизации.

---

## 2026-06-11

### Идея: «Казначейство-as-a-Service» — управляемые LP-волты для корпоратов
Корпоративные клиенты Сбера паркуют простаивающий SRUB/YSRUB в **курируемые
DLMM-стратегии** с авто-ребалансом и SLA по спреду/просадке, не управляя
диапазонами вручную («депозит+», но на маркет-мейкинге).
- **Ценность:** превращает idle-кэш казначейства в доходность от комиссий; клиент
  не вникает в bin-механику — выбирает риск-профиль (консервативный/сбалансир./агро).
- **Монетизация:** management fee (bps на AUM) + performance fee с заработанных
  комиссий; премиум-тариф за гарантированный спред.
- **Усилие: M.** Переиспользуем `AutoClaimScheduler`, `rebalancePlanner`, per-bin
  модель комиссий — нужен волт-обёртка (агрегатная позиция на пул стратегий) +
  отчётность AUM/PnL. Риск-движок IL уже частично есть.

### Идея: B2B FX-коридор для ВЭД (импортёры/экспортёры)
На базе уже существующих пар **SUSDT/SRUB, SEUR/SRUB** — предсказуемая конвертация
валюты для бизнеса с узким спредом (концентрированная ликвидность) и
расчётом «день-в-день» через ACID-ledger.
- **Ценность:** импортёру — прогнозируемый слиппедж и rate-lock на окно оплаты
  контракта; vs банковский кросс-курс — прозрачно и дешевле на объёме.
- **Монетизация:** комиссия за конвертацию + плата за «замок курса» (опцион-подобное
  окно); тариф за приоритетную ликвидность под крупный тикет.
- **Усилие: M.** Свечной движок свопа готов; нужен corporate-онбординг (лимиты,
  мультиподпись), endpoint rate-lock (зарезервировать котировку на N минут) и
  отчёт для бухгалтерии (переиспользуем self-describing `TransactionResponse` —
  символы/пара уже в API).

### Идея: «Ликвидность на Спасибо» — ритейл-лояльность → LP
Дать рознице вносить ликвидность **бонусами Спасибо** (в стеке уже есть
`04-spasibo-seed`) и зарабатывать комиссии в SRUB. Геймификация «Вложи Спасибо»
с маскотом Сберкотом, понятный Simple-режим.
- **Ценность:** монетизирует «спящие» Спасибо, заводит массового пользователя в
  DeFi-механику через знакомый бренд лояльности; виральный retail-funnel.
- **Монетизация:** спред + breakage невыкупленных баллов; апсейл в полноценные
  пары после первого позитивного опыта.
- **Усилие: S–M.** Маскот, Simple-режим и забор комиссий уже есть; нужен мост
  Спасибо↔SRUB (курс/лимиты) + витрина «доходность vs кешбэк».
