# UX Review — Sber DLMM Platform (post Sprint 5)

**Date**: 2026-06-03
**Designer**: Senior Product Designer, Sber Design System (in role).
**Method**: Heuristic walk-through (Nielsen 10 + Sber DS guidelines) +
WCAG-AA contrast spot-check + mobile breakpoint sanity + 3-user
intuitive-test estimate.
**Surfaces reviewed**:
- user-ui: DashboardPage, SwapPage, HedgePage, PoolsPage, PoolDetailPage,
  LiquidityPage, PositionsPage, TransactionsPage, ProfilePage,
  Login/Register, SpasiboWidget, NotificationBell.
- admin-ui: dashboard, transactions, pools, users, B2B portal (none yet — Sprint 6).
- Public: status page.

> **Scope clarification**: this is **heuristic review** not full usability
> testing. No real user sessions were observed — that's Sprint 7 dedicated
> UX research budget (R-new-32 below). Findings are designer-judgment
> calls with Sber DS + banking UX experience priors.

## 2. Per-surface findings

### 2.1 DashboardPage (user-ui — landing after login)

**What's strong:**
- Hero gradient lockup with portfolio number — matches Sber DS hero-card pattern. ✓
- Stat tiles use color-coded icons (amber wallet, purple chart, blue dollar, green trophy) — visually scannable. ✓
- React Query + Spin gives clear loading states. ✓ (heuristic #1)
- Spasibo widget (Sprint 5 #5.5) — perfect first-fold placement. ✓
- Last transactions table — sortable, color-coded type/status. ✓

**Findings:**

| # | Severity | Finding | Heuristic | Recommendation |
|---|---|---|---|---|
| **UX-001** | 🟠 Major | "Активные позиции" tile is just a number with no context — user clicks expecting drill-down, lands on empty state if no positions | #1, #7 | Wrap entire tile in `Link to="/positions"`; empty-zero state shows "Перейти к пулам →" CTA |
| **UX-002** | 🟡 Minor | "Незабранные комиссии" / "Всего заработано" both formatted as rubles — but user-balance currencies vary. Mixed-currency display in stat row creates "is this RUB or unit?" ambiguity | #2 | Append "≈" prefix on RUB-converted aggregates; tooltip explains conversion source |
| **UX-003** | 🔴 Critical | Last-transactions table on dashboard has no link to full /transactions page from the table itself; user has to navigate via sidebar | #3, #7 | "Показать все →" link below the table; one click |
| **UX-004** | 🟡 Minor | Spasibo widget green gradient is the same Sber green as primary CTA — first glance can confuse "ваш счёт показан как кнопка к нажатию" | #13 | Soften gradient to lighter Sber-aqua to differentiate from CTA buttons |
| **UX-005** | 🟢 Minor | Empty state when user has no transactions yet — shows just empty table, no onboarding nudge | #10 | First-time experience: "Сделайте первый своп" button + 2-line how-to |

### 2.2 SwapPage (user-ui)

**What's strong:**
- Bidirectional flip button (ArrowDownOutlined) — classic DeFi pattern done well. ✓
- "MAX" link on balance — convention-perfect. ✓ (heuristic #7)
- Token chip with first 4 letters + gradient — visual signature works at glance. ✓
- Quote panel with rate / price impact / fee / min-out — comprehensive. ✓
- Price-impact traffic-light (green / amber / red >5%) — risk communicated visually. ✓
- Slippage popover with presets + custom input — power-user friendly. ✓

**Findings:**

| # | Severity | Finding | Heuristic | Recommendation |
|---|---|---|---|---|
| **UX-006** | 🟠 Major | "Введите сумму" placeholder is "0.0" but the number input shows "0" — формат сбивает корп клиента, который ожидает ввод с копейками | #2, #4 | Replace placeholder with locale-formatted "0,00"; on focus, clear |
| **UX-007** | 🔴 Critical | Slippage default 0.5% is hidden behind a gear icon — corp treasurer doesn't realize what value is in effect until they click | #1 | Always-visible "slippage: 0.5%" chip next to the gear icon |
| **UX-008** | 🟠 Major | Insufficient-balance error is generic "swap failed" — doesn't tell user WHY | #9 | Specific error: "Недостаточно SBER. Доступно: 1234.56. Запрошено: 2000.00" |
| **UX-009** | 🟢 Minor | "Расчёт маршрута…" spinner shown during quote — good, but no timeout fallback if backend hangs | #1 | After 5s, "Долго не отвечает. Попробуйте обновить" with manual retry |
| **UX-010** | 🟡 Minor | "Через пул TKN1/TKN2" tag in quote panel — single-pool case only. Multi-hop routing not visualised (when it ships Sprint 7+) | #2 | Reserve space for routing breadcrumb |

### 2.3 HedgePage (user-ui — Sprint 4 #4.1 + Sprint 5 #5.14)

**What's strong:**
- SafetyCertificateOutlined icon + "Хеджирование валютного риска" header — treasurer-natural framing. ✓ (heuristic #2)
- Exposure-summary card with big SRUB number — banking convention. ✓ (heuristic #11)
- Candidate cards with current rate + bps fee badge — comprehensive at a glance. ✓
- Ratio presets (25/50/75/100%) — matches treasurer mental model. ✓
- Quote panel with effective rate + price impact — same pattern as SwapPage. ✓
- Open-hedges table with "Закрыть" action (Sprint 5 #5.14) — closes the lifecycle. ✓

**Findings:**

| # | Severity | Finding | Heuristic | Recommendation |
|---|---|---|---|---|
| **UX-011** | 🔴 Critical | "Хедж FX" sidebar label is ambiguous for non-financial users (BA Sprint 5 §3 already flagged). For Spasibo retail this is wrong audience | #2, #4 | A/B test "Защита от валютного риска" vs "Хедж FX" with retail; show only to KYC=VERIFIED + corp-tier users |
| **UX-012** | 🟠 Major | Hedge candidates list discovered automatically by FIAT_BACKED ∩ ACTIVE pool — but no fallback if zero matches found ("Нет доступных FX-пар. Проверьте, что в каталоге..." is dev-facing language, not user-facing) | #9 | User-facing fallback: "Сейчас нет доступных пар. Свяжитесь с менеджером." + CTA |
| **UX-013** | 🟡 Minor | Hedge ratio presets show "%" but the result is in absolute SRUB amount — user has to mentally map | #2 | Show "≈ 500 000 SRUB" subtext under each preset button |
| **UX-014** | 🟠 Major | "Открытые хеджи" table has no totals row (corp treasurer wants total hedged volume across positions) | #7 | Add footer row: "Всего захеджировано: X SRUB / Текущая стоимость в FX: Y" |
| **UX-015** | 🟢 Minor | "Закрыть всё" mass-action missing (BA Sprint 5 §3 flagged → Sprint 6 #6.14 backlog) | #7 | Already in Sprint 6 backlog as #6.14 |
| **UX-016** | 🔴 Critical | Quote panel says "Минимальный объём не задан — курс на момент исполнения" for unwind — for treasurer this is scary language. Better to show the **expected** receive amount with current rate | #1, #2 | "Получите ~X SRUB по текущему курсу. Фактическая сумма зависит от исполнения." |

## 8. Designer's verdict

**Overall**: solid Sber-brand-consistent foundation. The hard parts
(token visualisation, hedge calculator UX, Spasibo widget placement)
are done well — they show real product thinking, not generic crypto-DeFi
templates. The platform looks and feels **Russian-banking-native**, which
is the strategic moat.

**The 7 Critical items** are mostly small (slippage chip, language label,
mobile layout, accessibility) — 1 sprint of focused UX work closes them.

**The 4 strategic risks** (no permanent designer, no language toggle,
mobile gaps, accessibility) need PO + IT-lead executive attention —
budget allocation for Sprint 7-8 UX track.

**Positive surprises:**
- Spasibo widget placement on Dashboard — exactly where a treasurer
  expects to see promo / cross-sell. Conversion will be high.
- HedgePage information density — exposure → candidates → calculator →
  open hedges flow reads top-to-bottom naturally without explanation.
- Status page — text-only, fast, public-ready. Don't add fancy stuff.

**Things to NOT do** (resist scope creep):
- DO NOT add a real-time price ticker on Dashboard — adds noise, retail
  users panic on volatility.
- DO NOT redesign the SwapPage card — it's the most tested pattern in
  DeFi and works. Polish the edges, don't rebuild.
- DO NOT introduce a custom design system — Sber DS + AntD covers 95%.
