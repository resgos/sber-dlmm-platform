## Execution rhythm

Per batch:
1. **Plan** (5 min) — confirm files to touch, no scope creep
2. **Code** (manual, no agents — agents crash on session limit) — ship each unit, commit per unit
3. **Build + deploy** — `docker-compose build` then `up -d --force-recreate` only changed services
4. **Verify** — quick smoke probe (curl + bundle marker check)
5. **Push** — git push origin claude/elated-elgamal-dba521
6. **Update task** — TaskUpdate the batch task to completed
7. **Move to next batch immediately** — no pause

Expect ~1-2 batches per session (depending on remaining context budget).
