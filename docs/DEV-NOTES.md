# DEV-NOTES — память между автопрогонами

Короткие устойчивые грабли сборки/окружения/деплоя. 1–3 строки на пункт, без дублей.

- `lint:all` — цепочка через `&&`: предсуществующе красный `lint:styles` (inline-styles, line-keyed baseline,
  43 нарушения на 2026-10-24) обрывает её, и `lint:i18n`/`i18n-dead`/`dates`/`api` НЕ запускаются.
  Гонять их по отдельности: `npm --prefix <W>/dlmm-user-ui run lint:i18n` и т.д.
- `lint:i18n` (check-no-cyrillic-in-tsx) считает кириллические слова по файлу: перефразировка
  захардкоженной строки длиннее исходной валит ратчет — держать число слов или выносить в t().
- antd 5.29.3 в lock обоих UI: `destroyOnClose` → `destroyOnHidden` (с 5.25), диапазон в package.json ^5.25.0.
- Не писать `dayjs.locale('ru')` на уровне модуля: бандл один, все модули грузятся сразу, и это
  переключает dayjs глобально (EN-режим видел русский fromNow). Локаль — на экземпляр: `.locale(lng)`.
- `lint:styles` привязан к номерам строк: правка выше старого литерала сдвигает его и даёт «новое»
  нарушение — заменять сдвинутый литерал на токен (`var(--text-xs)` и т.п.), а не переписывать baseline.
- Перенос статусов в i18n: `t(\`profile.kyc.status.${key}\`)` — `lint:i18n-dead` сам вайтлистит префикс шаблона;
  после очистки файла ужать `scripts/cyrillic-baseline.json` правкой строки (а не `--update` по всему дереву).
- Причины/подписи из `src/lib/*.ts` (не .tsx) ратчет кириллицы не видит: при i18n компонента отдавать
  из lib `reasonKey`+`reasonParams` и переводить в компоненте (образец — positionHealth / HealthScoreBadge).
  `lint:styles` на 2026-10-27: 43 «новых» нарушения в 13 файлах (Pools/Transactions/Users/Suspicious и др.,
  считает оба UI) — проверять `grep -o "src/.*\.tsx" | sort | uniq -c`, что своего файла в списке нет.
- В компонентах с `const { t } = useTranslation()` не называть параметры колбэков `t` (`tokens.map((t) => …)`)
  — затеняет функцию перевода; брать `tok`/`item`. Тест i18n-компонента: после `changeLanguage('en')` уже
  отрендеренное переводится на лету — второй `render` даёт дубль, ждать через `findBy…`.
- Суммы в ₽ форматировать только через `src/lib/format.ts` (`formatRub`/`formatCompact`, EN: K/M/B);
  `StatCard.formatRub` с 2026-10-28 — лишь ре-экспорт. Чтобы добавить import, не сдвигая строки под
  `lint:styles`, его можно поставить внизу файла (ESM-импорты всплывают) — так сделано в StatCard.tsx.
- Docker Desktop может быть не запущен (2026-10-21: pipe dockerDesktopLinuxEngine не найден) — тогда
  статическая ветка: mvn/vitest/build без деплоя и curl; стек сам не поднимать.
