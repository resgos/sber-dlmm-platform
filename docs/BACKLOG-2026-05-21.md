## P0 — Critical (correctness blockers)

| # | Item | Where | Effort |
|---|---|---|---|
| P0-1 | **Canonical LB-DLMM L-units refactor.** Today `liquidity` per bin is stored as mixed-unit sum `amountX + amountY`. compositionFactor = reserveY / liquidity drifts past 1.0 after multiple adds; we clamp [0,1] tactically. Proper fix: switch internal accounting to canonical "L" = √(reserveX · reserveY / binPrice), with allocation distributing in L-units. Unlocks strategy weights that don't bias by mixed-unit price. | `LiquidityService`, `BinMath`, `PoolBin.liquidity`, all readers | L |
| P0-2 | **Bin-anchor convention.** Seed pools use `activeBinId = 2^23` as the anchor where `price ≡ basePrice`. `BinMath.binPrice(basePrice, binStep, binId)` still treats binId as offset from binId 0. Two callers were fixed by subtracting `activeBinId`; remaining callers + tests need audit. Better: add `BinMath.binPriceAtBin(pool, binId)` helper and migrate every site. | `BinMath`, `LiquidityService`, `SwapService`, `MarginWatchService`, pool-engine tests | M |
| P0-3 | **JPA `ddl-auto: validate` drift watchdog.** notification-service crashed on boot today because seed DB had column `read` but entity wanted `is_read`. Same class of bug could land on any service after a rebuild. CI lint to compare every `@Entity` field against the Liquibase changesets that should produce it. | new `dlmm-common-test-fixtures` module + GH Actions step | M |
| P0-4 | **SwapEventConsumer dedup by txId.** Today's consumer dedupes by `idempotencyKey` only; events lacking the key (every swap before Sprint 9-DS-r2) bypass and could duplicate on consumer restart. Add `findBySourceTxId(uuid)` lookup. | `dlmm-transaction-service` | S |
| P0-5 | **Outbox cleanup.** OutboxDispatcher drained 1830 backlogged events on first run today — never garbage-collected. Add scheduled DELETE for `processed_at < now() - 7 days`. | `dlmm-common.outbox` | S |
