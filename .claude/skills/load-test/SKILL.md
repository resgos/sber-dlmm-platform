# Нагрузочное тестирование REST API

Запусти субагента `load-tester` через Agent tool (subagent_type: "load-tester") и передай ему
одним сообщением всё, что известно из запроса пользователя:

- baseUrl цели (например http://localhost:8080);
- какие эндпоинты тестировать (пути без ведущего слэша);
- авторизацию: логин/пароль или готовый bearer-токен, если пользователь их дал;
- параметры нагрузки (VUs, длительность), если пользователь их назвал;
- явное разрешение на запись (POST/PUT/DELETE) или внешний хост, если пользователь его дал.

Результат субагента (блок «==== ИТОГ ====», таблицу по запросам и подсказки) передай
пользователю дословно, без пересказа своими словами.

Если субагент load-tester недоступен в этой сессии — выполни сам конвейер из
`load-agent/agent/SYSTEM_PROMPT_BODY.md` (probe → init → validate → run --smoke → run → отчёт).
